app.routers.comments.router = APIRouter(prefix="/comments", tags=["comments"])

HTTP endpoints under /comments for list / get / update / delete.

Comment creation is handled via POST /tasks/{id}/comments on the tasks router (keeps the Task → Comment relation explicit).
